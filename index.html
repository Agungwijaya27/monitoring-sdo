Setiap perubahan yang Anda simpan lewat form di web Vercel ini dikunci di memori browser Anda sehingga tidak akan hilang/balik lagi ketika halaman di-refresh.

🔄 Ingin hasil edit di Vercel otomatis tertulis balik ke Google Sheets untuk dilihat tim?

Agar saat Anda mengedit di Vercel datanya ikut mengubah isi tabel Google Sheets secara otomatis (2 arah), lakukan 1 kali langkah ini:

  1. Buka Google Sheets Anda, klik menu Extensions → Apps Script.
  2. Klik tombol "📋 Copy Kode Apps Script" di bawah ini, lalu Paste ke Apps Script dan tekan Ctrl+S.
  3. Klik tombol biru Deploy → New deployment → pilih Web app → Who has access: Anyone → Deploy.
